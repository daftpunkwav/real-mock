# types/

Shared frontend types.

| Path | Purpose |
| --- | --- |
| `generated/` | OpenAPI-derived API types — regenerated by `npm run generate:api-types`; never edit by hand |
| `domains/` | Hand-maintained frontend type definitions per domain (`api.ts` processor config / voice catalog / model profiles, `interview_ws.ts` WS protocol — aligned with `protocol/interview_ws.schema.json` by a backend test, plus `resume.ts`, `records.ts`, `report.ts`, `growth.ts`, `interview.ts`, `interview_prep.ts`) |
| `interview.ts` | Compatibility re-export of `domains/interview.ts` |
| `index.ts` | Barrel re-export |
| `css.d.ts` / `process.d.ts` / `talkinghead.d.ts` | Ambient module declarations |
